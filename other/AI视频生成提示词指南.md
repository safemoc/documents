# AI 视频生成提示词指南
> 一套专注于 AI 视频提示词写作的实用方法。

## 1. 核心观念：把提示词写成“导演执行单”

视频提示词不是形容词集合，而是一份同时描述空间与时间的执行指令：

- **空间层**：谁、在哪里、穿什么、光线和环境是什么。
- **时间层**：先发生什么、再发生什么、人物如何动作、镜头如何移动。
- **约束层**：哪些内容必须保持一致，哪些内容不能出现。

最实用的基础公式是：

> 主体 + 动作 + 场景 + 光影色调 + 镜头语言 + 视觉风格 + 画质 + 约束

对于多镜头视频，再加上明确的时间轴：

> 全局设定 + 分镜时序 + 声音设计 + 约束条件


## 2. 写作前的素材准备

给每个素材分配单一、明确的职责：

- 角色图：锁定人物面部、服装和体态。
- 场景图：锁定空间结构、布景和光线。
- 动作视频：参考人物动作和节奏。
- 运镜视频：参考摄影机轨迹，不复刻人物与场景。
- 音频：参考对白音色、环境声、节奏或情绪。
- 首尾帧：锁定开场构图和结尾落点。

参考素材应少而精。可先从 1–2 张角色图、1 张场景图、1 段动作或运镜视频、1 段音频开始，再根据任务复杂度增加。素材数量多不等于效果好，职责重叠或彼此冲突会稀释模型注意力。

推荐在提示词第一段建立映射：

> @图片1 是女主林夏，锁定面部、发型与白色风衣；@图片2 是男主周远；@图片3 作为咖啡馆场景；@视频1 只参考缓慢环绕运镜；@音频1 参考女主音色。

不要只写人名或 Asset ID。必须明确“图几/视频几/音频几”与人物、场景或任务的对应关系。



## 3. 特殊字符规范

在提示词中合理使用特殊符号，可以帮助模型准确区分音乐、音效、台词和字幕等不同信息类型。

| 信息类型 | 符号   | 示例                             |
| -------- | ------ | -------------------------------- |
| 音乐     | `()`   | `（背景中播放着快节奏的摇滚乐）` |
| 音效     | `<>`   | `<远处传来狗叫声>`               |
| 台词     | `{}`   | `{你好，世界。}`                 |
| 字幕     | `【】` | `【第一章：启程】`               |

当台词使用非中文、非英文的小语种时，应同时标注语种，避免模型误判发音。例如：

```text
{女主用日语说道：こんにちは。}
```

综合写法示例：

```text
（背景中播放着舒缓的钢琴曲）
<窗外传来细密的雨声和远处的雷声>
{女主低声说道：我们该出发了。}
【第一章：启程】
```

注意：符号只是信息分类工具，仍需写清声音来源、人物身份、语种、出现时间和是否需要字幕。若明确要求画面无字幕，则不要使用 `【】` 字幕标记，并在约束条件中写明“不生成字幕”。



## 4. 四步提示词工作法

### 第一步：写全局设定

一次交代清楚：

- 人物身份与稳定特征
- 场景时间与空间
- 整体视觉风格
- 核心剧情目标

示例：

> 深夜的现代急诊室，冷白色顶灯与窗外蓝色雨光形成对比。@图片1 的年轻女医生为主角，保持其面部、发型和白大褂一致。整体采用低饱和现实主义电影风格，讲述她在抢救结束后独自消化情绪的瞬间。

### 第二步：按时间轴写分镜

使用“整数秒时间戳 + 镜头序号”组织分镜，让模型同时理解每段内容的持续时间、发生顺序和镜头边界。

> 0–6 秒｜镜头1：中景固定机位，医生摘下口罩，缓慢靠在墙边，呼吸仍然急促。
>
> 6–15 秒｜镜头2：镜头缓慢推近至面部特写，她低头闭眼，手指轻轻颤抖，眼眶逐渐泛红。
>
> 15–24 秒｜镜头3：侧面近景，窗外救护车红光短暂扫过她的脸，她深呼吸后重新站直。
>
> 24–30 秒｜镜头4：镜头平稳拉远，她转身走回抢救室，画面停在关闭的门上。

一段镜头尽量只指定一种主要运镜。动作要连续，写出“停顿—转身—抬手”之类的过渡关系。

### 第三步：把情绪写成可见动作

少写“非常悲伤”“十分紧张”，多写摄影机能够看到的信号：

- 悲伤：低头、肩膀轻颤、眼眶泛红、攥紧衣角。
- 紧张：呼吸急促、频繁看表、手指敲击、眼神闪躲。
- 愤怒：双拳握紧、下颌紧绷、胸口起伏、从牙缝中说话。
- 释然：缓慢呼气、肩膀放松、露出淡淡微笑、望向远处。

### 第四步：声音和约束

声音应明确区分对白、环境声、音效和背景音乐：

> {女主低声说道：我没事，继续吧。} 音色参考 @音频1。保留<雨声、走廊脚步声和远处医疗设备声>，不生成背景音乐，不生成旁白。

通用约束词：

> 人物面部稳定、五官清晰、人体结构正常、动作自然连贯；角色服装、发型和场景结构前后一致；无闪烁、无跳帧、无穿模、无多余人物、无字幕、无水印。



## 5. 通用模板

```text
【素材映射】
@图片1 是[角色A]，锁定[面部/发型/服装]；
@图片2 是[角色B]；
@图片3 作为[场景]参考；
@视频1 只参考[动作/运镜/节奏]，不复刻其中的[人物/场景]；
@音频1 用于[音色/对白/节奏/背景音乐]。

【全局设定】
[时间]，[地点]，[角色与关系]。
[光线和色调]，[视觉风格]。
核心剧情：[一句话剧情目标]。

【分镜时序】
[0]–[X]秒｜镜头1：
[景别]，[主体动作]，[主要运镜]，[关键环境变化]。
声音:[<环境声/音效>];
约束:[分镜内约束];

[X]–[Y]秒｜镜头2：
[景别@图片2]，[动作过渡]，[情绪的可见表现]，[主要运镜]。
{[角色@图片1]以[语气]说道：[台词]}，音色参考 @音频1。
声音:[<环境声/音效>];
约束:[分镜内约束];

[Y]–[Z]秒｜镜头3：
[高潮或转折]，[镜头落点]。
声音:[<环境声/音效>];
约束:[分镜内约束];


【声音】
不生成[背景音乐/旁白]。


【约束】
保持角色面部、发型、服装和场景结构一致；动作自然连贯；
无闪烁、无跳帧、无穿模、无多余人物、无字幕、无水印。
禁止:[变脸/换装/...]


【输出风格】
[光影要求，细节描述，色彩需求，风格确定]
```



## 6. 提示词生成前检查清单

- 是否一句话明确描述了视频目标？
- 是否明确了主要人物、场景和核心内容？
- 每个参考素材是否有明确用途？
- 人物、场景、视频、音频素材是否正确对应？
- 是否描述了视频发生的时间顺序？
- 是否明确主要动作和动作变化过程？
- 是否将抽象情绪转化为可观察的行为描述？
- 是否明确声音需求（对白、环境声、音效、音乐）？
- 是否明确需要保持一致的内容？
- 是否明确禁止出现的内容？
- 是否删除重复、矛盾或无法执行的描述？
