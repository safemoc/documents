它把学习分成六个层次：

> 记忆 → 理解 → 应用 → 分析 → 评价 → 创造

| 层级            | 核心问题         |
| ------------- | ------------ |
| 记忆 Remember   | 你能说出它是什么吗？   |
| 理解 Understand | 你能用自己的话解释吗？  |
| 应用 Apply      | 你能实际使用吗？     |
| 分析 Analyze    | 你能拆解原理和关系吗？  |
| 评价 Evaluate   | 你能判断方案优劣吗？   |
| 创造 Create     | 你能基于它设计新方案吗？ |
例如学习用户画像：

- 记忆：知道用户画像的定义；
- 理解：能解释用户画像与用户标签的区别；
- 应用：能制作一个画像；
- 分析：能判断画像背后的数据是否充分；
- 评价：能判断画像对产品决策有没有帮助；
- 创造：能设计一套适合自己项目的用户研究体系。
